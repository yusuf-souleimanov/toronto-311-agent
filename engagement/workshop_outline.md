# Client Workshop: 10 Slides, 30 Minutes

Audience: a 311 contact centre manager and an IT lead. No code on screen.

1. **The problem.** About 500,000 customer-initiated requests in 2025; top types are bins, property standards and wildlife (from `stats.city_totals`).
2. **What we heard.** Residents don't speak in City categories; routine requests take agent time. (From the use-case canvas.)
3. **The proposal in one picture.** Simplified architecture: chat → agent → tools → resident confirms.
4. **Live demo, happy path.** "Pothole outside 250 Dufferin St" → draft → yes.
5. **Live demo, where it's careful.** Raccoon on the sidewalk → asks "alive or dead?"; gas smell → 911; property tax → escalated. Show the sidebar audit log.
6. **Does it work?** Eval table: majority 6%, TF-IDF 90%, Claude (from report), plus cost per message.
7. **Where it struggles.** Emotional and indirect messages; keyword hijacking ("sidewalk"); synthetic test data. Being honest here builds trust.
8. **Governance.** Human-in-the-loop policy, top risks and controls, fairness by writing style.
9. **What you'd need to have in place.** Prerequisites checklist and go/no-go.
10. **Pilot proposal.** 15 request types, web channel only, 8 weeks, success metrics from the canvas, first step: label 500 real messages.
